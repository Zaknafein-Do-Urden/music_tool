# 即兴伴奏

边唱歌边点按钮切换和弦，钢琴伴奏自动按节奏循环。

## 用法

1. 选一个调：用 ▲▼ 升降（唱着舒服就行，不确定先用 C），欢快的歌用大调，伤感的歌可以试小调。再选拍号和速度。
2. 点任意和弦开始，伴奏会一直循环；再点别的和弦，会在下一拍（或下一小节）切换。
3. 底部的小按钮可以随时切换伴奏风格，以及换和弦是"下一拍"还是"下一小节"生效。按"✨ 加花"，小节末尾所有乐器来一段过门。
4. 点 ⚙ 打开设置：
   - **乐队**：钢琴 / 摇滚乐队（鼓、贝斯、吉他）/ 中国风（古筝、琵琶、长笛）。第一次切换要下载音色，稍等几秒。
     中国风下和弦按钮会自动换成"五声版"（比如 5 变成 5sus），去掉五声音阶里没有的音，听起来更开阔、更有中国味。中国风常用走向：`1 → 6m → 4 → 5sus`、`6m → 4 → 5sus → 1`。
   - **伴奏织体**：试听这个乐队的全部风格，用 ★ 选 3 个常用的放到底部。
   - **自动加花**：关 / 每 4 小节 / 每 8 小节。
   - **音量**：每件乐器单独调，比如鼓太吵就调小。
   - 改动立即生效，点窗口外面就能关掉设置。
5. 不知道按什么：看和弦按钮下面的"常用走向"（换乐队、换大小调会跟着变），照着按就行。另外，大调从 `1` 开始，套 `1 → 5 → 6m → 4` 循环；小调试试 `1m → 6 → 3 → 7`。一句快唱完时按 `5`，下一句回到 `1`。

## 麦克风功能

第一次使用时 Safari 会询问麦克风权限，请允许。

- **🎤 定调**：伴奏停下后，清唱或哼你想唱的歌 10–20 秒，app 推荐一个调，点"用这个调"即可。
- **💡 推荐**：打开后边唱边看，绿色描边的按钮是推荐的下一个和弦（淡绿是第二推荐）。用得越多，它越记得你在哪段旋律后喜欢按什么。
- **🎧 耳机**：戴耳机时打开，音质更好；不戴耳机时关着，app 会尽量滤掉外放的伴奏。
- **● 录音**：人声和伴奏分开录，录完可以分别调音量、对齐，再保存或分享成 WAV。录音刷新页面就没了，记得保存。

## 录音室

另一个页面 `record.html`（伴奏页的设置里有入口），专门录自己唱歌：
- 戴上耳机，点红色按钮开始，再点停止。可以先"🎵 选伴奏"选一个音频文件，录音时从耳机里放。
- 录音存在手机浏览器里，刷新不会丢；点"保存/分享"可以存到"文件"或发给别人。
- 录完会自动分析：判断你唱的是什么调、音域多宽。点"听·看曲线"边听边看音高曲线：绿色是准的，黄色有点偏，红色偏得多，左右拖动曲线可以前后跳。

iPhone 上建议在 Safari 里"分享 → 添加到主屏幕"，用起来像 app。如果没声音，检查音量和静音键。

## 本地运行

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000 。

## 部署到 GitHub Pages

1. 推送到 GitHub：`git push -u origin main`
2. 仓库 Settings → Pages → Source 选 "Deploy from a branch"，Branch 选 `main`、目录 `/ (root)`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/music_tool/`（录音室是 `https://<用户名>.github.io/music_tool/record.html`）。之后每次推送到 main 都会自动更新，新页面不需要额外设置。

后续路线见 [docs/ROADMAP.md](docs/ROADMAP.md)。
