# 即兴伴奏

边唱歌边点按钮切换和弦，钢琴伴奏自动按节奏循环。

## 用法

1. 选一个调：用 ▲▼ 升降（唱着舒服就行，不确定先用 C），欢快的歌用大调，伤感的歌可以试小调。再选拍号和速度。
2. 点任意和弦开始，伴奏会一直循环；再点别的和弦，会在下一拍（或下一小节）切换。
3. 底部的小按钮可以随时切换伴奏风格，以及换和弦是"下一拍"还是"下一小节"生效。点 ⚙ 打开设置，可以试听全部 12 种伴奏风格，用 ★ 选 3 个常用的放到底部。
4. 不知道按什么：大调从 `1` 开始，套 `1 → 5 → 6m → 4` 循环；小调试试 `1m → 6 → 3 → 7`。一句快唱完时按 `5`，下一句回到 `1`。

## 麦克风功能

第一次使用时 Safari 会询问麦克风权限，请允许。

- **🎤 定调**：伴奏停下后，清唱或哼你想唱的歌 10–20 秒，app 推荐一个调，点"用这个调"即可。
- **💡 推荐**：打开后边唱边看，绿色描边的按钮是推荐的下一个和弦（淡绿是第二推荐）。用得越多，它越记得你在哪段旋律后喜欢按什么。
- **🎧 耳机**：戴耳机时打开，音质更好；不戴耳机时关着，app 会尽量滤掉外放的伴奏。
- **● 录音**：人声和伴奏分开录，录完可以分别调音量、对齐，再保存或分享成 WAV。录音刷新页面就没了，记得保存。

iPhone 上建议在 Safari 里"分享 → 添加到主屏幕"，用起来像 app。如果没声音，检查音量和静音键。

## 本地运行

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000 。

## 部署到 GitHub Pages

1. 推送到 GitHub：`git push -u origin main`
2. 仓库 Settings → Pages → Source 选 "Deploy from a branch"，Branch 选 `main`、目录 `/ (root)`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/music_tool/`。之后每次推送到 main 都会自动更新。

后续路线见 [docs/ROADMAP.md](docs/ROADMAP.md)。
